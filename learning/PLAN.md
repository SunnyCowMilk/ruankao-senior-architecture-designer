# 学习计划

## 目标与节奏

- 学习目标：建立系统架构思维，能独立设计中等复杂度的 AI 应用系统并解释关键取舍；2027 年软考高级作为阶段性检验。
- 时间投入：每周约 6～8 小时，以理解和实践为先，不追求固定每日打卡。
- 参考资料：仓库的 2022 年《系统架构设计师教程》第 2 版和考试大纲；必要时补充现代架构、分布式与 AI Agent 工程资料，明确注明来源和版本。
- 学习方法：重点章节深入互动，其他章节按考纲系统覆盖；章节不必按书本顺序，但每章最终都应有覆盖记录。

## 贯穿项目：多用户 AI Agent 平台（抽象案例）

- 需求：账号隔离、任务执行、可扩展的 Skill 插件、模型调用和文件存储。
- 递进设计：需求与质量属性 → 模块边界 → 数据模型/API → 任务与并发 → 隔离、安全、可靠性 → 架构评估。
- 设计取舍优先于堆组件：需解释何时不使用微服务、Redis、消息队列或独立沙箱。
- 所有案例使用公开或虚构信息，不记录工作中的保密设计。

## 每节完成标准

1. 用自己的话解释核心概念，能举出适用与不适用场景。
2. 至少回答一个推理问题，并得到反馈；必要时补足误区。
3. 产生简短原创笔记；重点节完成一项具体设计或真题练习。
4. 在 `PROGRESS.md` 记录状态、掌握度（0 未学 / 1 了解 / 2 理解 / 3 应用 / 4 掌握）和下一步。

每月复盘一次学习投入和项目成果，必要时调整计划；不以预估考试日期或固定章节速度倒逼学习。
