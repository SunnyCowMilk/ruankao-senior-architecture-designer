## 日常学习流程

1. 在 `PROGRESS.md` 找到当前小节；按 `content/INDEX.md → 教材 INDEX.md → 章 INDEX.md → 节文件` 定位原文。
2. AI 每次围绕一个可消化的知识点讲解，联系实际工程场景，并提出一个问题。
3. 学习者先自行作答，AI 反馈优点、缺漏和设计权衡，再继续下一个知识点。
4. 结束小节后由学习者用自己的话复述，完成小练习或真题，形成原创笔记。
5. 经学习者确认后更新进度；把不确定结论标注为待验证，而非冒充掌握。
